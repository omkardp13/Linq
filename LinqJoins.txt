using System;
using System.Linq;

class Customer
{
    public int Id { get; set; }
    public string Name { get; set; }
}


class Order
{
    public int Id { get; set; }
    public int CustomerId { get; set; }
    public string ProductName { get; set; }
    
}


class Program
{
    static void Main()
    {
        var customers = new Customer[]
        {
           new Customer { Id = 1,Name="Pankaj"},
           new Customer { Id = 2,Name="Rahul"},
           new Customer { Id = 3,Name="Puja"}
        };

        var orders = new Order[]
        {
            new Order { Id = 1,CustomerId=1 ,ProductName="Mobile"},
            new Order { Id = 2,CustomerId=2 ,ProductName="Clothes"},
            new Order { Id = 3,CustomerId=3 ,ProductName="AC"}
        };


        var result = from customer in customers             
                     join order in orders
                     on customer.Id equals order.CustomerId
                     select new { customer.Name, order.ProductName };

        foreach (var x in result)
        {
            Console.WriteLine(x.Name +" Buys "+ x.ProductName);
        }
       
        Console.ReadLine();
    }
}


------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

1. Inner Join
Description: Combines elements from two sequences where a specified condition is true.

Example:

var result = from customer in customers
             join order in orders
             on customer.Id equals order.CustomerId
             select new { customer.Name, order.ProductName };

Result: Includes only the matching elements from both sequences.

---------------------------------------------------------------------------------------------------------------------

2. Group Join

Description: Produces a hierarchical result set, where elements of one sequence are grouped with matching elements from another sequence.

Example:

var result = from customer in customers
             join order in orders
             on customer.Id equals order.CustomerId
             into customerOrders
             select new { customer.Name, Orders = customerOrders };

Result: Each customer is paired with a collection of their orders.

---------------------------------------------------------------------------------------------------------------------


3. Left Outer Join

Description: Includes all elements from the first sequence (left side) and the matching elements from the second sequence (right side). If no match is found, a default value is included.


Example:

var result = from customer in customers
             join order in orders
             on customer.Id equals order.CustomerId
             into customerOrders
             from order in customerOrders.DefaultIfEmpty()
             select new { customer.Name, ProductName = order?.ProductName ?? "No Order" };

Result: All customers are listed, even those without orders.
---------------------------------------------------------------------------------------------------------------------

4. Cross Join

Description: Produces a Cartesian product of two sequences (every combination of elements from both sequences).

Example:

var result = from customer in customers
             from order in orders
             select new { customer.Name, order.ProductName };

Result: Every customer is paired with every order.

---------------------------------------------------------------------------------------------------------------------

5. Full Outer Join (Simulated in LINQ)

Description: Combines all elements from both sequences, including those that do not have matching elements.

Implementation: LINQ does not have a direct full outer join operator, but it can be achieved by combining Group Join and Union or using two Left Outer Joins.

Example:

var leftJoin = from customer in customers
               join order in orders
               on customer.Id equals order.CustomerId
               into customerOrders
               from order in customerOrders.DefaultIfEmpty()
               select new { customer.Name, ProductName = order?.ProductName ?? "No Order" };

var rightJoin = from order in orders
                join customer in customers
                on order.CustomerId equals customer.Id
                into orderCustomers
                from customer in orderCustomers.DefaultIfEmpty()
                select new { Name = customer?.Name ?? "No Customer", order.ProductName };

var fullOuterJoin = leftJoin.Union(rightJoin);

Result: Includes all customers and orders, even if they don't match.

---------------------------------------------------------------------------------------------------------------------

6. Self Join

Description: Joins a sequence with itself to compare elements within the same collection.

Example:

var result = from customer1 in customers
             join customer2 in customers
             on customer1.Id equals customer2.Id
             where customer1.Id != customer2.Id
             select new { customer1.Name, customer2.Name };

Result: Pairs of elements within the same collection that satisfy the condition.
By choosing the appropriate join type, you can effectively query and combine data to meet your application's requirements.
